## 当協会の会員について

IAESTE Japan の活動は、その趣旨に賛同する企業や大学、個人の皆様により成り立っています。会員として参画していただいている下記の企業・大学・個人各位に御礼を申し上げるとともに、今後一層のご支援を賜りたくお願い申し上げます。

- [会員情報](members.md)

会員に関してご不明な点は、お気軽にお問い合わせください。

- [IAESTE Japan 事務局連絡先](contact.md)

### 正会員 (大学会員及び個人会員)

総会での議決権行使により当協会の意思決定に参画いただくとともに、当協会運営及び運営資金のご支援をいただいています。  
また、大学会員に関しては研修応募を早期にお知らせし、在校生の申請手数料と研修事務手数料は他大学の半額としています。

| 会員種別 | 年会費 |
| ------- | ------ |
| **大学会員** | 40万円 |
| **個人会員** | 5千円 |

### 事業協力会員

事業協力会員は、外国人学生にインターンシップの機会を提供していただいている企業・大学・研究機関等の受入機関です。

### 賛助会員

賛助会員には、当協会の運営資金のご支援をいただいています。

| 年会費 |
| -------- |
| 1口20万円 |


## ご寄付のお願い
当協会がその活動を一層発展させ、意義深いものとするご寄付を随時受け付けております。

## 学生委員 / ボランティア

### 学生委員活動

IAESTE は学生委員の活動によって支えられています。学部生の方、 IAESTE の学生委員会の活動に参加してみませんか?  
学生委員会は大きく分けて 2 つの活動を行っております。

#### 日本から海外へ研修に行く研修生を対象にした活動

- インターンシップ説明会・質問会
- 研修準備会
- 研修報告会
- IAESTE Connect Japan / IAESTE RINGS

#### 海外から日本へ研修に来る研修生を対象にした活動

- Contact Person（研修生の日本での生活のサポート）
- 日本文化を紹介するイベントなどの企画開催

現在、主に関東地区学生委員会 (TLSC = Tokyo Local Students' Committee) がこれらの活動を行っています。  
東北地区では IAESTE 研修経験者の方々が活動しています。

TLSC の活動詳細はこちらをご覧ください。

- [ホームページ](https://tlsc.iaeste.or.jp/)
- [インスタグラム](https://www.instagram.com/iaeste_japan_tlsc/)

### ボランティア

IAESTE の運営など、広くその活動を手伝っていただけるボランティアの方を随時募集しています。  
ご興味のある方はぜひ相談していただき、スキルや経験を活かせる場を見出してください。
