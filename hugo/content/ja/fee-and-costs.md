このページでは IAESTE Japan への納入額と、研修に関わる渡航費、滞在費等をご説明します。<br>

## IAESTE Japan への納入額

申請手数料と研修事務手数料を納入してください。費用の詳細は以下をご確認ください。

### 申請手数料

| 区分  | 大学会員校生 (*1) | 非会員校生 (*1) |
| -------------------- | --------: | ---------: |
| **初めての応募**           | 6,000 JPY | 12,000 JPY |
| **IAESTE 研修経験者の応募** | 0 JPY     | 0 JPY      |

### 研修事務手数料

| 区分  | 大学会員校生 (*1) | 非会員校生 (*1) |
| -----------------| ---------: | ----------: |
| **初めての応募**          | 60,000 JPY | 120,000 JPY |
| **IAESTE 研修経験者の応募** | 42,000 JPY | 84,000 JPY  |

1. 現在の大学会員校は [こちら](members.md) をご覧ください。　大学院進学などにより応募時と研修時で所属する大学が異なる場合、応募時あるいは研修時のどちらかで大学会員校に所属すれば、大学会員校生の金額が適用されます。

## その他の費用

| 項目               | 内容                |
| ------------------ | ------------------ |
| **渡航費**              | 航空券などの費用はご自身の負担です |
| **滞在費**              | 通常、**生活に十分な額を受入機関が支給**します。現地 IAESTE 主催のイベント参加費用などについては、 自己負担となる場合が有ります |
| **海外傷害保険料**       | 手配も含めご自身の負担となります。なお、**保険加入は必須**です |
| **査証 (VISA) 取得費用** | ご自身の負担となります。 **VISA 取得手続きに関しては受入国のIAESTEがサポート**します |

## 研修が実施されなかった場合の返金について

結果的に研修が実施されなかった場合は研修事務手数料を返金する場合があります。
