## 申し込みについて

> [!CAUTION]
> 1. 研修には Exchange Internship と Global Internship の2種類があります。その違いは、[オファーについて](offers.md) をご覧ください。
> 2. 9月募集と4月募集では、研修可能時期や選択できるオファーの種類が異なります。詳しくは [研修を始めるまで](how-it-works.md) をご参照ください。
> 3. 英語能力のスコアを応募期間内に提出することが必須ですので、早めに試験を受けスコアを取得してください。
> 4. お問い合わせは、[Contact](contact.md) に記載の受付時間にて、このページ内の書類に記載されていない内容について対応いたします。

## 応募時の英語能力のスコア最低条件

応募時にオファータイプ（[オファーについて](offers.md) を参照）を選択して頂きます。選択したオファータイプでスコアの最低条件が決まります。

| 試験 | Exchange Internship | Global Internship |
| ---------- | :-----: | :------: |
| **TOEFL iBT** | 4 | 4.5 |
| **IELTS** | 5.5 | 6.5 |
| **ケンブリッジ英語検定** | B2 First | C1 Advanced |
| **実用英語技能検定** | 準1級 | 準1級 |
| **TOEIC Listening and Reading** | 650 | 785 |

### 応募後の英語能力に関する留意事項

1. 海外の IAESTE は TOEFL、IELTS、またはケンブリッジ英語検定で英語能力を評価するケースが多いです。
2. 受入国によっては Speaking や Writing の証明が必須です。TOEIC Listening and Reading の証明しか持っていない場合、追加の面談による認定か、異なる試験の受験が必要になります。この場合は事務局より追って連絡があります。
3. 応募後、受入機関が受入可否を決めるために応募学生にインタビューを行うことがあり、実践的な能力が必要とされます。
